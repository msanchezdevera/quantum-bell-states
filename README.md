# quantum-bell-states

Practical work using Qiskit and IBM Quantum Composer to generate Bell States and quantum random numbers through superposition and entanglement.

## Contents

- Quantum random number generator
- Bell State circuit
- Superposition
- Quantum entanglement

## Technologies

- Python
- Qiskit
- Qiskit Aer

## Installation

```bash
pip install -r requirements.txt
```

## Run

Random number generator:

```bash
python random_number_generator.py
```

Bell State circuit:

```bash
python bell_state.py
```
